# Review rules

Important:
- A rule about items implemented in `cli.py` or `store.py` instead of `items.py`.
- A stored file of the previous format that no longer loads.
- An acceptance criterion without a test, or a test that would pass without the change.
- Reading the clock or the file system in `items.py`.

Nit:
- Names that do not match the existing style; missing error message detail.
